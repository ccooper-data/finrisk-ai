# Independent security identifier corroboration

Name similarity is discovery evidence, never security identity.

FinRisk can extract CUSIP/ISIN-shaped identifiers from independently sourced filing evidence and compare them with a candidate security's ISIN. Exact ISIN matches or a CUSIP embedded in a 12-character ISIN are explicit corroboration signals.

Extraction alone does not establish that an identifier belongs to the issuer. Every extracted identifier must retain filing/accession/source provenance and be reviewed in its document context before an accepted security mapping is created.
