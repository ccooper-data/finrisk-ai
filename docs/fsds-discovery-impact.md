# FSDS discovery impact

This experiment measures downstream value of SEC filing-era names using the same hard-case population and same EODHD discovery floor as the prior diagnostic.

It compares candidate discovery before versus after adding filing-era SUB names. Outputs count new candidate issuers, candidate-count increases and top-score improvements.

This remains discovery evidence only. An improved fuzzy match does not create an accepted CIK-to-security mapping.
