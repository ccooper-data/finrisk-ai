# Historical security resolution evidence

Every proposed issuer-to-security link is materialized as evidence, including issuer CIK/name and active dates, candidate security identity and active dates, provider provenance, name score, date-overlap result, stronger identifier evidence and final decision.

Name similarity alone cannot create an accepted mapping. Exact names remain review candidates unless stronger identifier evidence supports the link. Temporal non-overlap always rejects the candidate.

This structure is provider-neutral so paid or public historical-security sources can be evaluated under the same rules.
