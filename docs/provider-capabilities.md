# Historical market provider capability gate

A convenient price API is not automatically suitable for historical distress research.

Before integration, a provider is assessed for delisted-security coverage, historical identifier support, point-in-time identity, provenance, delisting returns, corporate actions and adjustment semantics.

Historical ablation eligibility requires delisted coverage, historical identifier history, point-in-time identifiers and provenance. Missing delisting-return/corporate-action support remains an explicit warning and may require supplemental evidence.
