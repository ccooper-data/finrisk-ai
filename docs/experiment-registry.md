# Experiment registry

FinRisk keeps negative results.

Statuses:
- exploratory: valid experiment, not eligible for production/portfolio claims;
- candidate: evidence is promising but promotion requirements remain;
- promoted: accepted result with explicit decision rationale;
- rejected: tested approach intentionally not advanced.

A rejected experiment is not deleted. Its metrics, data lineage and decision rationale remain part of the project evidence so future work does not repeat disproven assumptions.
