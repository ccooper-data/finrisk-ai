# Filing-era SEC name evidence

The SEC submissions API exposes current registrant name, former-name periods and recent filing dates/accessions. FinRisk preserves these separately so historical aliases can be compared to the time window of the issuer's filings.

The SEC Financial Statement Data Sets additionally document that registrant name is the legal entity name recorded in EDGAR as of the filing date. That filing-era source can be integrated later for bulk historical name snapshots.

This evidence remains issuer-name evidence, not security/ticker identity.
