# Identifier-backed security promotion gate

An exact identifier match is necessary but not sufficient for historical-security acceptance.

Evidence can reach security-acceptance review only when the identifier is independently corroborated, appears in explicit common-equity context, belongs to the CIK under review, is temporally compatible with the candidate security and is not ambiguous.

Passing this gate does not itself set accepted_security=true. It permits the evidence package to enter the separate security-resolution review.
