# Historical security evidence tiers

Candidate-strength evidence is triaged without accepting a security mapping.

Tier A: top score >=0.90 and margin >=0.08. Eligible for a limited price-access probe, but still not accepted identity.
Tier B: top score >=0.90 but ambiguous. Requires identifier/security-type/temporal corroboration.
Tier C: weaker discovery candidate. Requires CUSIP, ISIN, historical ticker or other independent identifier evidence before deeper work.

Every row remains accepted_security=false until the separate identifier-backed resolution contract is satisfied.
