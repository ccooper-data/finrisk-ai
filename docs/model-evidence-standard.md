# Model evidence standard v2

Every promoted model result must identify:
- exact code commit;
- frozen data artifact digests/IDs;
- temporal split;
- feature contract;
- out-of-time metrics;
- known limitations.

Exploratory experiments may exist without promotion, but their limitations must remain attached to the evidence. A result is not recruiter-facing production evidence merely because it has a high metric.

Market models additionally require historical-identity and survivorship-gate evidence. Macro models using current-vintage revised history remain exploratory until release/vintage-safe data is used.
