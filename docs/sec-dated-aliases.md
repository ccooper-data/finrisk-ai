# SEC dated alias evidence

SEC submissions JSON provides the registrant's current name and formerNames entries with date ranges. This supplements the historically cumulative CIK/name file with temporal alias evidence.

CIK remains the issuer identity. A dated alias is evidence that SEC associated that legal/conformed name with the CIK during a period; it is not historical ticker evidence.

Each submissions response is source-hashed independently so alias evidence can be traced to the exact SEC payload used.
